# KittyAPI v2.13.3 升级说明

2026-10-21，来源：codex。目标站点 kittyapi.xyz，凤凰城服务器。

上游基线：ranxi2001/sub2api v2.13.3，提交
`42596307d2c8d74fdb098ceaebc20440fd96b854`。生产定制版本
`2.13.3-kitty.2`。保留三站账号会话、媒体钱包、计费价格、访问限制和
提示词正文 400/413 修正。

账号级请求时区开关及编辑控件退役；历史字段保留以便恢复，但不参与请求改写。
全局开关控制 HTTP、WS 和兼容转发；自动模式使用实际请求所选出口，检测失败不以
服务器时区冒充代理时区。客户端已带的时区请求头可同步，普通用户文本、日期、位置
及语言偏好不改写。晚期兼容处理移除内容来源标签时，在请求内保留有限数量的文本哈希，
保护明确标注为普通文本的环境示例。

账号列表旁的独立“2FA添加 / 批量”入口移除；保留添加账号中的 GPT 2FA。
普通导入不再根据废弃的 login_environment 参数切到浏览器登录，而使用后台协议任务。
选定代理后保持代理身份，不自动转为服务器直连；官方安全验证失败只返回脱敏诊断。
登录运行时固定为经过官方摘要校验的 2.13.3，协议与传输源文件哈希符合已有安全修正。

上游新增的 11 个 SQL 迁移均以完整文件名识别，不覆盖已有自定义媒体钱包迁移。
在隔离 PostgreSQL 恢复副本上重复执行迁移，核对历史校验和、账号数、密钥数、分组数、
用量记录数和精确余额合计。正式迁移及切流的实际结果记录在服务器发布清单中。

支付兼容保留既有严格查询身份、签名歧义拦截、重复入账保护和敏感错误脱敏。
上游新增测试改用完整的支付身份数据；不降低站点既有安全校验。

发布前端构建须使用 VITE_KITTY_SITE=kittyapi；保留上一版已发布哈希资源以兼容打开的页面。
源代码、数据库与运行恢复集永久保留，代码回退不执行数据库反向迁移。

切流前复核发现上游 v2.13.3 已发布，继续合入 SIWC 授权诊断和请求惩罚功能。
请求惩罚保持默认关闭，不自动改变客户使用限制。新迁移 293 同样进行副本演练
和兼容恢复验证。2FA 普通导入仍使用后台协议，不改成 SIWC 手工授权。

最终页面验收补齐中文全局时区说明，去掉已退役的“手动账号时区”描述。
