# 算力图片上游与自动跟价

视频与图片共用 `/admin/video-upstream` 页面，独立页签与保存接口。图片默认关闭自动同步、关闭自动导入、加价为0，由管理员自行设置；不改已有视频设置和图片渠道。

在 OpenAI API Key 账号配置算力地址、密钥和精确型号名，绑定开启图片生成的 OpenAI 分组。开启自动导入后，全部显式配置型号按公开价格目录匹配（支持别名）；无有效价格或映射冲突时保留原价、显示提示。没有价格的新品不会被按零成本发布。上游默认分组倍率必须为1。

图片售价使用原有 `image_model_prices` 最终价，不再叠分组倍率。跟涨与跟跌可分别控制；手动售价（包括0）优先。在旧分组价格格修改任一档位也会退出该型号自动覆盖。恢复自动需明确保存空白手动输入。每次生成1张；按次报价的1K/2K/4K格不代表上游支持这些尺寸。

## 图片协议

外部使用标准 `/v1/images/generations` JSON 或 `/v1/images/edits` multipart；Banana 家族按上游文档转换为 Chat 协议。保留完整型号大小写。支持标准图片 JSON、HTTPS URL、data URI、图片二进制与异步结果查询。非图片字节、空响应、失败状态或多图数量不符不按成功结算。蒙版及流式图片不在首版合同内。

建议每个逻辑请求传唯一 `Idempotency-Key`，重试原请求保留同一值。`Prefer: respond-async` 可在上游返回任务编号后提前取得本站任务；使用同一 Key GET `/v1/images/tasks/simg_…`。长请求使用既有 JSON 空白保活时 HTTP 状态可能已提交，客户端也应检查返回正文的 `status`。

请求先保存任务与最终价快照，再付费提交；数据库恢复工作只查上游结果，不重新生成。成功扣费与用量记录同事务去重；查结果不二次扣费。无法判断是否提交成功时保留 `unknown` 等待人工核实。请求本体、参考素材与上游密钥不写任务表。临时结果保存24小时，再清空结果字节；任务ID、归属、售价和结算证据保留。上游URL有自己的有效期，客户应及时下载。

画布按所选 Key 的动态模型能力调用本站适配器，保留原视频链路，图片多张操作拆为单张任务。4K选项请求4096长边，实际输出清晰度以上游型号为准。

## 验收范围

31个已选型号均在公开按次价格目录中。测试使用合成上游、合成账号和隔离数据库；不消耗真实上游余额，不等于31个真实型号均已付费出图验收。上线不自动读取上游密钥、不创建生产账号、不修改原售价。

## 恢复注意

269仅新增图片任务表与索引，不重写旧业务表。旧版二进制无法在新增迁移账本上重新启动，需使用附带269迁移的兼容回退包；有未完成图片任务时保留新版结算实例，不能通过恢复旧数据库回滚客户交易。
