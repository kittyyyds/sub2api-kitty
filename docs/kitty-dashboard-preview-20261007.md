## 预览

在 `frontend` 执行 `pnpm exec vite --config vite.preview.config.ts`，打开 `http://127.0.0.1:4317/preview.html#/dashboard`。渠道页为同地址的 `#/monitor`。仅监听本机回环地址。

顶部预览工具栏支持两站品牌切换、深浅色、加载失败/已读失败/空列表/简易模式。所有数字和公告均为明确标注的示例数据。预览复用正式组件、store、API 模块，由独立入口的 Axios adapter 在内存中响应；没有生产代理、真实会话或上游调用。充值、密钥、使用记录和兑换入口已直接挂载本站原页面；Axios adapter 在本地返回所需示例数据，阻止订单、密钥创建、兑换等提交。其他非目标页显示说明。

`preview.html`、`preview/`、`vite.preview.config.ts` 不参与正常生产构建。正常构建仍由 `index.html`、`src/main.ts` 进入真实鉴权与 API；没有在正式入口增加认证豁免或演示数据开关。

## 布局与数据

| 功能 | 真实数据来源与行为 |
|---|---|
| 首页概览 / 用量分析 | 首屏概览；切到分析时按需加载原有图表、平台消费与额度、最近调用；保留原业务组件 |
| 今日 / 总消费 | `/api/v1/usage/dashboard/stats` 的 `today_actual_cost` / `total_actual_cost`；不拿标准价代替实际扣费 |
| 今日 / 总 Token | 同接口返回的权威聚合及输入、输出、缓存明细；不在前端估算消费，不改变时区口径 |
| 余额 / 密钥 | `/api/v1/auth/me` 的余额及统计接口的总数/启用数；充值入口遵守支付关闭、余额充值关闭及简易模式 |
| RPM / TPM | 现有接口近5分钟的每分钟平均吞吐；明确不是账号限额 |
| 公告正文与历史 | `/api/v1/announcements` 现有用户可见列表；去除前端截断20条，分页、检索、未读筛选；正文经 Markdown + DOMPurify 过滤 |
| 已读状态 | 用户点击公告打开详情后调用现有 `/announcements/{id}/read`；与顶部公告中心共用 store；失败保持未读并提示；批量最多5个并发，换账号后停止剩余批次 |
| 紧凑 V1 渠道 | 1080px 居中；同一网格，按平台/名称/分组/模型筛选；保留探测时间线、延迟、PING、个人倍率、可用性时间窗、详情、可选配额、自动刷新与隐藏标签页暂停 |

公告“历史”限后端仍发布且用户有权查看的公告（包括已读）。不绕过发布时段、用户/余额/订阅定向权限，不向普通用户开放已撤回或过期公告。首页每条公告显示两行摘要，点击打开完整 Markdown 详情。摘要先剥离 HTML，详情使用 DOMPurify。历史支持分页与按需展开搜索。

## 第二版本：按用户截图纠正结构和交互（2026-10-08）

用户指出第一版遗漏欢迎卡片、变化文案和真实快捷入口，明确认可“用量分析”独立页签。本次仍只在同一本地分支改动，不推送、不部署。

- 顶部现在是完整圆角渐变欢迎卡片，包含概览标记、按本地时段更新的问候、每日短句、站内充值与联系客服。页签保留在左上方。
- 按用户要求，同一浏览器、同一用户、本地自然日内短句保持不变；次日随机选择一条不同短句，持续打开时也会更新。仅保存日期和句子编号，键使用用户 ID，不使用登录凭据。禁用存储时使用当前访问的内存缓存；跨设备不保证同句。
- 静态核对同行公开用户仪表盘资源后发现，对方短句是 sessionStorage 会话缓存随机选择，没有按天比较；因此本站“每天一次”是按用户最新要求独立实现，不能宣称与对方完全一致。
- 充值链接 `/purchase`，沿用原余额充值页面、权限开关和简易模式限制；客服复用原 `CustomerContactDialog`，与侧栏相同的分类、内容及资源。
- 右侧改为单张账户状态卡片：余额、启用/总密钥、近实时 RPM/TPM；保留后端5分钟平均吞吐口径。三项快捷操作复用原组件，路由分别 `/keys`、`/usage`、`/redeem`；密钥页仍由用户点击创建按钮打开原表单。
- 公告改为逐条摘要列表，打开即记录已读，失败保留未读并可重试；完整历史仍可分页、搜索。连续打开不同公告时分别记录，不因上一条请求未完成而漏记。
- 本地浏览器实点五个入口、核对客服与侧栏内容/图片相同、打开密钥创建弹窗、验证原充值套餐页、使用记录图表和兑换表单。测试没有提交订单、创建密钥或兑换余额，没有外部网络请求。
- 桌面、深色和390px手机截图为证据目录 `dashboard-v2-*.png`；检查截图时等待页面样式切换稳定，避免把侧栏过渡动画当作最终布局。
