## 预览

在 `frontend` 执行 `pnpm exec vite --config vite.preview.config.ts`，打开 `http://127.0.0.1:4317/preview.html#/dashboard`。渠道页为同地址的 `#/monitor`。仅监听本机回环地址。

顶部预览工具栏支持两站品牌切换、深浅色、加载失败/已读失败/空列表/简易模式。所有数字和公告均为明确标注的示例数据。预览复用正式组件、store、API 模块，由独立入口的 Axios adapter 在内存中响应；没有生产代理、真实会话或上游调用。快捷操作链接到原业务路由，预览对非目标页显示说明，不执行充值、密钥创建等写入。

`preview.html`、`preview/`、`vite.preview.config.ts` 不参与正常生产构建。正常构建仍由 `index.html`、`src/main.ts` 进入真实鉴权与 API；没有在正式入口增加认证豁免或演示数据开关。

## 布局与数据

| 功能 | 真实数据来源与行为 |
|---|---|
| 首页概览 / 用量分析 | 首屏概览；切到分析时按需加载原有图表、平台消费与额度、最近调用；保留原业务组件 |
| 今日 / 总消费 | `/api/v1/usage/dashboard/stats` 的 `today_actual_cost` / `total_actual_cost`；不拿标准价代替实际扣费 |
| 今日 / 总 Token | 同接口返回的权威聚合及输入、输出、缓存明细；不在前端估算消费，不改变时区口径 |
| 余额 / 密钥 | `/api/v1/auth/me` 的余额及统计接口的总数/启用数；充值入口遵守支付关闭、余额充值关闭及简易模式 |
| RPM / TPM | 现有接口近5分钟的每分钟平均吞吐；明确不是账号限额 |
| 公告正文与历史 | `/api/v1/announcements` 现有用户可见列表；去除前端截断20条，分页、检索、未读筛选；正文经 Markdown + DOMPurify 过滤 |
| 已读状态 | 用户明确点击后调用现有 `/announcements/{id}/read`；与顶部公告中心共用 store；失败保持未读并提示；批量最多5个并发，换账号后停止剩余批次 |
| 紧凑 V1 渠道 | 1080px 居中；同一网格，按平台/名称/分组/模型筛选；保留探测时间线、延迟、PING、个人倍率、可用性时间窗、详情、可选配额、自动刷新与隐藏标签页暂停 |

公告“历史”限后端仍发布且用户有权查看的公告（包括已读）。不绕过发布时段、用户/余额/订阅定向权限，不向普通用户开放已撤回或过期公告。超长正文在卡片内滚动，历史详情可独立打开。
