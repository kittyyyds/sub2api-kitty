# 视频账号模型自动适配与价格档位

2026-10-09，来源 codex。目标版本 2.9.9-kitty.13；实际发布状态以本次验收记录为准。

账号里配置的确切模型是管理员确认开放的范围。开启“按账号模型自动补齐分组”后，后台按同步间隔读取绑定的算力视频账号及其分组模型限制，将这些型号补齐为分组售价。不会发布供应商目录里未被账号选择的其他型号。暂停账号不删除其配置；账号删去的型号仅移除自动管理且仍跟价的条目，独立手动售价保留。

新型号使用上游成本和已保存的加价；现有型号继续遵守全局及型号级跟涨、跟跌和加价设置，已有手动售价优先。模型别名按真实上游型号取价。同名模型映射到不同上游型号或不同供应商时，不静默选价，后台显示异常提示。未获得有效初始价格不免费接单，读价失败继续保留最后有效价格。

已知型号使用参数目录，不再用静态“待实测”标记阻止管理员选择的型号。未知确切型号走同一上游的通用视频协议，公开说明明确具体参数以上游为准；传输及素材安全校验仍保留。这不等于其他供应商或任何私有协议都已适配。

生成价与参考视频价分开处理。缺少参考视频收费依据时保留生成价，仅拒绝费用不明确的视频参考输入；不推断免费或与生成同价。未来上游提供明确参考收费后，下次同步可更新该能力。所有既有在途任务继续使用创建时的价格和能力快照。

客户模型价格页在没有分辨率分档价格时，从能力数据展示对应 4K、480p、720p 等档位；缺少单独档位表不再显示误导的横线。有分档价时仍按分档价显示，不回退为免费。这个展示修复不更改价格。

验收覆盖账号全部18型号、别名、后续新增/删除、未选型号不发布、手价和跟涨不跟跌保留、未知型号、缺参考价格以及模型广场/画布列表/报价一致。使用合成请求与隔离数据库，不进行真实付费视频生成。没有数据库迁移，Canvas应用版本保持不变。
