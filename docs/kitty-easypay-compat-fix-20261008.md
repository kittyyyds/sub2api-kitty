# EasyPay 实付金额与回调兼容修复

日期：2026-10-08。目标版本：2.9.9-kitty.6。

## 问题与行为

官方查单确认实际付款 10.01 元，但本站订单应付 10.00 元时，之前安全补丁的严格相等校验拒绝入账，与原有最多多付 0.05 元的履约规则冲突。本次统一这两处规则：平台确认已付、商户/订单/交易号匹配，通知金额与查单金额一致，且没有少付、最多多付 0.05 元时允许履约。本金仍按订单约定金额入账，额外的分币不扩大余额、赠送或返佣本金。

EasyPay 通知允许缺失或为空的展示字段 name，以及省略时默认 MD5 的 sign_type。仍对实际收到的字段原样验签，不补造字段；显式非 MD5 算法仍拒绝。商户、订单、交易号、金额、类型、状态、签名仍为必填。参数白名单、重复键及结构歧义拒绝、官方已付款查单和交易号去重全部保留。

历史日志只有“缺少必填字段”，没有原始回调或字段名，无法证明历史那次通知具体缺少什么。本次补充只输出固定字段名称的诊断，不记录签名、密钥、恢复令牌或原始回调。重复 PAYMENT_VERIFICATION_PENDING 审计保留首条，避免反复触发已有唯一索引错误。

## 保护范围

- 不修改订单、余额或人工补款记录，不重放生产回调，不创建支付测试订单，不调用本站补单/履约接口作为验收。
- 保留过期宽限期和状态转换条件；已超过宽限期的人工补偿订单，迟到通知和再次核实不会自动重复充值。一般性的人工补款与订单绑定功能不在本补丁范围内。
- 两站分别构建品牌版本，保留刚上线的首页、响应式布局及全部前端文件；迁移目录原字节保留，不新增数据库迁移。
- 固定签名 Gateway Group Prompt 1.2.1 的兼容版本增加 kitty.6，不放宽其他插件或未来版本限制。
