# 视频模型价格展示与无限画布新标签入口

2026-10-09，来源 codex。版本 2.9.9-kitty.12；生产状态以对应验收回执为准。

## 客户模型价格页面

“模型价格 → 视频生成”展示视频分组保存的实际客户售价。账号同步出的上游目录与成本不等于已发布的售价；分组还没有任何有效型号价格时，不自动把供应商目录公开成免费或可调用模型。

管理员在视频分组读取目录、选择要开放的型号并保存后，客户才能看到对应价格。手价留空继承上游价格及已设置加价，填写手价则固定；已有任务继续使用创建时的价格快照。本次页面修复不修改这些计费规则。

页面按型号的计费方式展示每条或每秒价格，并补充分辨率档位和参考视频秒价。视频分组的配置价就是最终余额扣费单价，不再次乘分组、用户或时段倍率。零价格与缺价分开，缺价不能作为免费展示。公开接口不返回后台的原始成本、加价控制或供应商凭据。

型号描述来自已适配的参数能力：可选时长、分辨率、参考素材数量和组合限制等。不会把供应商未验证的速度或稳定性宣传当成本站保证。真实付费生成不属于这次展示验收。

## 无限画布入口

侧边栏“无限画布”、入口页“进入无限画布”和视频任务页的画布链接，在新的浏览器标签页打开，保留原中转站页面。链接继续使用同源、带版本参数的画布地址，登录方式和本地项目存储不变。

## 发布范围

本次更新 Sub2API，Canvas 应用本身继续使用现有 v0.8.0-kitty.2。没有新增数据库迁移。两站保留自己的历史 SQL、静态资源与原配置，逐站验证候选后切流；旧实例继续处理在途连接。

用户已授权 YYDS 视频组25导入其账号205现有九个精确型号，沿用生成每秒加0.1、参考每秒加0.1、每条加0.5、跟涨不跟跌的已存规则。导入由双站发布验收后单独执行正常管理接口完成；没有授权扩大到目录其他型号。KittyAPI目前没有视频分组，仅更新展示与入口功能。

此次补适配的两个按条SD及三个官转稳定按秒SD，上游未明确参考视频费用，均暂不接受参考视频，创建任务和扣费前即拒绝。文生、参考图片及符合组合约束的音频可用，音频必须配图片。不能将缺少参考价字段解释为免费；待核实费用后再开放。所有能力依据上游公开文档适配，本轮没有进行真实付费生成验收。
