# 视频分组定价与上游模型价格探测

2026-10-09，来源 codex。候选版本 2.9.9-kitty.11；上线状态以生产验收记录为准。

## 使用方式

视频分组允许先以空价格表保存。没有有效定价的型号不能创建视频任务。账号绑定仍使用现有视频平台隔离，不混用文本分组。

视频 API Key 账号的“自动探测上游模型价格”读取已适配供应商的公开默认组价格，保存型号、按条/按秒单位、生成价、参考价和分辨率价格。不会读取倍率接口，不会修改账号倍率、成本倍率或客户售价。上游读取失败不使账号保存失败，保留上次有效快照；未适配供应商显示不支持。其他平台保持原倍率探测。公开默认组报价不能证明账号的个性折扣成本。

在视频分组内读取目录并选择型号。新“读取上游价格”操作只刷新目录，不改其他分组售价。每个型号的手动售价留空，保存时由服务端使用上游成本和加价规则计算有效售价；填写金额（包括0）则固定售价，并关闭该型号的自动跟价。填写统一生成价时同步该型号已有分辨率档位，仍可随后单独编辑分辨率和参考价。清空手动价切回上游来源。

上游来源的生成每秒、参考每秒、每条加价分别配置，型号级设置优先于全局。跟涨与跟跌可分别开关；周期调价需要全局自动同步和该型号自动跟价同时开启。保存规则会应用一次，已提交任务保持原价格快照。读价失败沿用最后有效售价；没有可信初始价格时拒绝继承，绝不将空值当作0。

现有无 video 元数据的手工价格保持旧逻辑。旧自动价格未被强制启用全局同步。价格按现有接口原值与本站记账口径处理，本次不静默换汇、不改既有客户余额。

## 官方直连 SD 与 4K

基于供应商公开 `/api/docs/content` 与 `/api/pricing` 的 2026-10-09 快照适配。非4K官方直连SD2.0/SD2.5共10项分别读取 video_multi 输出和参考价，不假设参考价永远等于输出价。单独的明确0参考价与缺价区分。

官方直连SD2.0 4K接口仅提供输出秒价，未明确参考视频费。因此先允许文生、参考图及符合上游条件的音频组合；在请求出站前拒绝视频参考。4K分辨率按型号能力开放，不向所有型号全局添加。参考音频不能单独使用，上游要求音频1.8–30秒。文档带†的时长和素材上限属于供应商未逐项实测的标注，本地协议适配不等于真实生成验收。

统一视频应用和无限画布按后端能力目录显示，型号需由管理员自行选择和开放账号白名单。本次不自动开放线上型号、不创建收费测试任务。旧Kitty Studio专用视频流程不属于统一能力适配入口。
