## 交互

- 供应商默认：保存空 request_path，沿用后端默认接口。
- Chat 兼容：/v1/chat/completions、/chat/completions；智谱另提供 /api/paas/v4/chat/completions。
- OpenAI Responses：/v1/responses、/responses。
- Anthropic：/v1/messages、/messages。
- Gemini 默认路径由后端按模型生成，界面仅展示模型占位说明，不保存字面模板。
- 特殊路径选择“自定义路径”再输入。历史特殊路径自动回显，输入框在清空或输入恰好等于预设时仍保持打开。重开或切换编辑对象正确重置。

路径选项按当前平台/协议筛选。选择路径只更新 request_path，不切换供应商、请求协议或替换已有密钥。自定义路径原有后端校验保留。

## 使用边界

路径选择不转换请求协议。修改平台或协议后，已有不匹配路径会保留在自定义输入中，应重新选择适用路径。特殊上游路径仍须自行填写；供应商默认会跟随当前后端适配器，不保存界面显示的模型占位符。
