# QQ 入群欢迎与邮箱确认

消费审核仅判断注册账号的累计实际消费资格，不证明邮箱所有权。正式 QQ 绑定仍需邮箱收件人在确认页面核对 QQ 身份并明确点击确认。确认前没有账户查询权限，不写正式绑定，不发绑定奖励。

配置入口为「QQ 机器人 → 群管理 → 对应群 → 入群欢迎与邮箱确认」。每群独立配置欢迎开关、自动邮箱确认开关、审核通过欢迎正文和其他成员欢迎正文。旧配置默认关闭。正文只写问候，绑定状态和邮件结果由程序追加。

只有本站成功审批的 self_apply 申请，可在 30 分钟内与同群、同 QQ 身份的实际 GROUP_MEMBER_ADD 事件关联。只使用最近一次申请，配置和注册邮箱必须保持一致。审核记录仅临时保留用户 ID、邮箱哈希和规则摘要，不保留完整答案、邮件令牌或消费金额。记录一次使用，30 分钟后清理。

- 已消费审核通过且未绑定：复用注册邮箱发起 10 分钟有效的单次确认邮件；发送成功后才告知已发送。
- 已有相符绑定：继续使用原绑定。
- 账号或 QQ 已有冲突绑定：保留原绑定，提示管理员核对。
- 邀请、人工放行、缺少可信审核记录或原审核记录失效：普通欢迎和邮箱/网站绑定码指引。
- 邮件受限或失败：提示实际状态，不声称绑定完成；发送失败会撤销对应确认令牌。

欢迎只在实际入群时发送，审批成功不会提前发送。GROUP_MEMBER_ADD 不是 QQ 被动回复可引用的事件，因此使用主动群消息，不伪造 msg_id/event_id。需要在 QQ 开放平台订阅 GROUP_MEMBER_EVENT，并具备主动群消息权限；目标群也需允许机器人主动发送。平台拒绝、网络超时或缺少消息 ID 时，记录结果未确认，不自动补发。

稳定事件键、成员事件顺序、数据库发送预留与邮件限额共同抑制重复执行。欢迎预算为每群每分钟 10 次、每机器人每分钟 20 次、每群滚动 24 小时 800 次；这是欢迎自身的预算，其他主动通知仍可能占用 QQ 平台的共享额度。它不调整客户模型 API 的限速或计费。

本功能复用既有 QQ 表和邮件确认页，不新增迁移。运行记录可筛选「入群欢迎与邮箱确认」，查看邮件成功、失败、受限、原绑定复用、冲突或 QQ 发送失败等结果。真实 QQ 权限与 SMTP 链路需以实际入群的处理结果为准。
