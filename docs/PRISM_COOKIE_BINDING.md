# Prism 手动会话绑定（本地试验版）

> 历史本地验证记录（2026-09-27）。当前 `2.8.18-kitty.4` 候选的范围与上线边界以 `PRISM_RELEASE_20260928.md` 为准；此文不作为部署或真实工作区认证回执。

记录日期：2026-09-27（UTC）；来源：codex。

已按用户选择恢复手动填写界面。当前版本不提供浏览器自动登录、一次性命令、后台获取 Cookie 或服务器自动登录功能。

1. 在本地 SUB 管理后台，编辑自己的普通 GPT/OpenAI OAuth 账号。
2. 打开「Prism 协议（实验）」。
3. 自行取得该账号的 Prism 会话后，填写「Prism 会话 Cookie」。
4. 「Prism User ID」为可选项，没有明确值时留空。
5. 选择使用 Prism 的模型，或明确勾选账号允许的全部文本模型。
6. 保存账号设置。

Cookie 通过现有账号编辑接口加密保存，不在账号详情中回显。已有绑定时，Cookie 留空表示保留原绑定。模型选项不代表上游已授予权限。

本次仅恢复本地版本的操作方式，保留手动 Prism 适配、加密存储、OAuth 刷新保护、原有账号数据和其他功能；没有回灌数据库或改动生产。

自动绑定代码和原始验收资料已保存在 D 盘归档中。当前程序不注册原 prism-bind 回调及任务路由，原一次性命令不再可用。
