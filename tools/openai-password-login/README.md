# 普通 GPT OAuth 密码与 2FA 登录执行器

来源：2026-11-16，codex。复用用户现有 VM2 的隔离登录组件，仅取得普通 Codex OAuth 授权，账号与后续模型请求由 SUB 管理，不创建 VM、不调用 VM2 推理接口。

登录运行时固定为 MIT 项目 poxiao33/toSub2 的提交 `8548397e89bf80e508eda64a87e0d556d43abc84`，来源归档 SHA256 为 `ddb061cff7c87b5c931615ef10e904795852a6bfef8f23d9998634ca77ade9a0`。保留运行时 LICENSE；安装和受限适配见 scripts/codex-login/prepare.py。镜像继承已验证的 VM2 运行时依赖，仅增加明确的直连模式，已配置代理失败时不回退直连。

任务按管理员归属隔离。密码及 2FA 密钥经 stdin 传给一次性子进程，不保存到数据库、命令行、环境变量或日志。授权结果只在内存保留五分钟，领取一次后销毁；取消、超时、终态回收会清理进程与临时目录。额外安全、邮箱和手机号验证需要改用官方浏览器授权，不自动绕过。

部署使用单独的内部 Docker 网络和服务密钥文件，无公网端口，无 Docker socket；容器只读文件系统，临时文件使用受限 tmpfs。后端必须通过普通管理员认证，并禁止审计日志记录本组接口的请求体。执行器没有复制 VM2 的管理凭据。
